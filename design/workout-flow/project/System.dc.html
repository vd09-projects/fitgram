Why tokens: each scales with screen width (× width / 375); a literal does not, so on a wider phone it renders smaller than the tokens around it (TICKET-052: the plan name sat below its own exercise rows).
Older boards use in-between sizes; read them as the nearest token: ≤10.5 xSmall · 11–12.5 small · 13–14.5 xMedium · 15–16.5 medium · 17–20 large · 22+ xLarge.
Off the scale in code today: the logger's exercise title is a literal 25 (ExerciseNavHeader); 44 literal sizes in 15 files, to move onto tokens.
